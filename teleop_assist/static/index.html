Darstellung und Verbindung

Die 3D-Ansicht rekonstruiert die sichtbare Oberfläche aus einer einzelnen RGB-D-Kamera. Beim seitlichen Blick können Lücken sichtbar werden. Verdeckte Rückseiten werden nicht erfunden; das ist keine vollständige Stereoaufnahme.

Für Quest/PICO dieselbe Adresse im Headset-Browser über HTTPS öffnen. Bei einem lokalen Zertifikat zunächst dessen Vertrauensstellung im Headset herstellen. HTTP über eine LAN-IP erlaubt kein WebXR. Desktopbedienung bleibt verfügbar.
